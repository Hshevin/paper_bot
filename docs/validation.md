# 验证记录

日期：2026-10-31。

## 核心回归

运行 `.venv/bin/python -m unittest discover -s tests -v`，71 项测试通过，验证：

- broad/strict 查询、UTC 日期、版本 ID、安全 XML、响应大小、并发串行限速、错误页码拒绝。
- 关键词边界、硬排除、研究描述传递、严格分数格式、原文证据校验。
- 每目标独立主题、频率和重启恢复，已共享主题只评分一次，多个方向合并排序和按目标去重。
- WebUI 配置直接改变路由，绑定与解绑写回同一配置，保存失败回滚内存。
- 分页失败恢复、超过 30,000 条自动拆窗、跨重启续传，完整结束前不推进成功游标；手动范围与自动游标隔离。
- 模型失败暂停、低分复用、发送失败重试、分析/发送期间解绑、关闭前取消和等待。
- 非管理员拒绝、明确模型提供商、错误不回显密钥、纯文本 QQ 发送、手动全文报告分段。
- PDF 流式限额、缓存、取消清理、真实 PDF 文本提取、空扫描件拒绝、文本分块完整性与模型调用上限。

所有模型和 QQ 调用均为模拟，不使用真实账号、API 密钥或付费额度。

## 真实 AstrBot SDK

官方源码 `v4.10.4`，commit `45bce6fe7657efb79eb0fb7cbc66d21b88ee6dc4`，安装完整宿主依赖后运行：

```sh
.build/sdk-venv/bin/python scripts/check_sdk.py --sdk-path .build/AstrBot
```

通过真实插件 import/Star 注册、metadata/schema 加载、10 个管理员命令和参数转换、原生 MessageChain、真实 Context/PaperService 初始化及终止。绑定命令实际保存 AstrBotConfig，调用宿主 WebUI 的真实配置保存/校验函数后重载，确认新间隔生效，并确认解绑在同一配置中禁用订阅。

脚本设置网络审计钩子，禁止建立网络连接；该项是 SDK 集成验证，不是已登录 QQ 的端到端联调，也不是 WebUI 浏览器视觉测试。

## 在线接口与未验证范围

对 arXiv 官方 HTTPS API 的只读小范围请求得到 **HTTP 429**，客户端正确报错并保留进度。遵守限流，没有立即反复请求；未将其报告为真实抓取成功。

旧版原生 macOS 源码仅迁移目录，没有重新构建、安装或修改本机已安装应用。插件升级不自动迁移原生用户数据库。
