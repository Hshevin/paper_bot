# AstrBot Paper Bot implementation

用户授权：升级论文筛选并改为可安装 AstrBot 插件，向配置的 QQ 群/用户定时推送，远端 Hshevin/paper_bot。

1. 保留原生版本至 legacy/macos；插件根目录 main.py、metadata.yaml、_conf_schema.json。
2. Python 核心：描述/阈值/匹配依据；默认分类宽召回，strict 可选关键词门槛，词边界与别名显式输入。不把低分删除，不伪造错误评分。
3. 官方 arXiv API 日期分页，串行请求>=3秒，失败不推进成功游标；大结果分页续传。SQLite 持久状态、待分析队列、按目标发送记录。LLM 和推送失败可重试，消息成功才记发送。
4. AstrBot 原生提供商接口、生命周期、管理员指令；每个群聊/私聊独立订阅主题与间隔，按相关性合并排序。所有设置可通过 WebUI 修改，聊天命令写回同一配置；后台可取消。首次安装默认不发送。
5. 回归测试（模拟 HTTP/LLM/QQ，不真实发消息）、官方源码接口兼容检查、真实 arXiv 只读冒烟、文档、提交推送指定空远端。

验收：AstrBot 从 Git URL 可加载配置与入口；有配置即可定时抓取、筛选、逐目标推送；不同目标不串方向，重复运行去重，失败目标不影响成功目标；无 API 密钥写入仓库；无管理员授权不能改目标或触发付费分析。PDF 精读仅由管理员手动触发，报告返回当前会话。真实QQ/LLM联调需要用户在宿主配置账号及密钥，不伪造验证结果。
